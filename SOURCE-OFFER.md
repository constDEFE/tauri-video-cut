## Corresponding Source Code

The complete corresponding source code for the GPL-licensed components
distributed in this application consists of:

1. **The Compilation Scripts**: The exact scripts used to control the
   compilation, environment setup, and harvesting of the executables are
   preserved in this repository under `scripts/build/` at the tag
   corresponding to this release.
2. **The Upstream Source Modules**: The preferred form of the upstream
   modules for making modifications, at the exact revisions used:
   - **FFmpeg**: [n9.0.1](https://github.com/FFmpeg/FFmpeg/tree/n9.0.1)
   - **mpv**: [v0.41.0](https://github.com/mpv-player/mpv/tree/v0.41.0)

You are not compelled to download the source code alongside the object
code. The source code remains available from this repository and the
linked upstream repositories.
